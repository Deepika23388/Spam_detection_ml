# 📩 SMS Spam Detection using Machine Learning

An end-to-end Natural Language Processing (NLP) and Machine Learning web application that classifies SMS messages as **SPAM** or **HAM (Not Spam)** with **97.85% accuracy**.

Built using **Python, Scikit-learn, and Streamlit**.

---

## 🚀 Features
- **Real-Time Classification:** Instant prediction of user-input messages.
- **Confidence Scores:** Displays probability percentage for spam vs ham.
- **Interactive UI:** Clean web interface built with Streamlit.
- **Trained on Real Data:** Uses the UCI SMS Spam Collection dataset (5,572 messages).

---

## 🛠️ Tech Stack & Algorithms
- **Language:** Python
- **Data Manipulation:** Pandas, NumPy
- **Feature Extraction (NLP):** TF-IDF Vectorizer
- **Classification Algorithm:** Multinomial Naive Bayes
- **Evaluation Metrics:** Accuracy, Precision, Recall, Confusion Matrix
- **Web Framework:** Streamlit
- **Model Serialization:** Pickle

---

## 📊 Model Performance
- **Accuracy:** 97.85%
- **Precision (Spam):** 100% (Zero False Positives)
- **Recall (Spam):** 84%
- **F1-Score (Spam):** 91%
